Analytics isn't switched on yet

No tracking script is loading, so nothing is being recorded. Three steps to start collecting data — it takes about two minutes.

Create the account

Sign up free at goatcounter.com. Pick a site code — voltwrench is the obvious one.

Add the code

Open assets/app.js and set analyticsCode to that code. Nothing else needs changing.

Make it shareable

In GoatCounter's settings, set the dashboard to public. The client can then view stats here without an account.

The full dashboard is hosted at and updates in real time.

What's counted

  • Page views and unique visitors
  • Which pages get read, and for how long
  • Referrers — Google, WhatsApp, direct
  • Country, browser and screen size

Panel blank? GoatCounter only allows embedding when the dashboard is set to public — use the direct link instead.

A note on the numbers

No cookies are set and no personal data is stored, which is why the site needs no cookie banner. The trade-off is that a returning visitor on a different device counts twice. Treat the figures as a reliable trend, not a precise headcount — and expect them to run lower than tools that track more aggressively.
